# Changelog

All notable changes to Localis will be documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning.

## [Unreleased]

### Added

- Initial Localis monorepo foundation.
- Deterministic project audit and secret detection.
- Environment doctor for Node.js, Git, and Ollama.
- Privacy Gateway with scoped context, redaction manifest, and SHA-256 payload identity.
- Loopback-only Ollama discovery and generation.
- `privacy`, `models`, and `ask` CLI commands with safe JSON output and dry runs.
- Schema-constrained local Ollama change proposals with redacted context.
- `propose` CLI workflow with context dry runs and no-overwrite plan export.
- Validated change-plan schema with SHA-256 preconditions and path boundaries.
- Diff-first `apply`, private backup history, and conflict-safe `undo` workflows.
- Terminal escape-sequence sanitization for human-readable output.
- Vercel-ready Localis product website.
