# Localis: как мы строим приватное AI-пространство для разработки

_Черновик для Habr, vc.ru и инженерных сообществ. Made by KebiLab._

AI-инструменты ускоряют разработку, но часто требуют слишком много доверия.
Разработчик отдаёт сервису репозиторий, ждёт непрозрачный результат и получает
изменения, происхождение которых трудно проверить. Мы решили построить другой
процесс: сначала факты, затем видимая граница данных, потом предложение и только
после подтверждения — изменение файлов.

Так появился **Localis** — private, local-first AI workspace для разработчиков.
Его короткая формула: **Your code. Your machine. Your AI.**

## Что уже умеет Localis

Localis объединяет CLI и Tauri-приложение вокруг одного ядра. Детерминированный
аудит находит секреты, опасный `eval`, интерполяцию shell-команд, пустые
`catch`, незакрытые TODO и персональные данные. Каждая находка содержит правило,
важность, файл, строку, объяснение и способ исправления. Это не «оценка от
нейросети», а воспроизводимый сигнал.

```bash
localis audit .
localis audit . --json
```

У находок есть стабильные ID. Можно выбрать конкретную проблему и попросить
локальную модель подготовить узкий план:

```bash
localis fix 1 . --out localis-fix.json
localis apply localis-fix.json .
localis apply localis-fix.json . --yes
```

Первый `apply` показывает diff. Запись начинается только с `--yes`. Перед ней
Localis сверяет SHA-256 исходных файлов, блокирует path traversal и symlink-
атаки, создаёт локальную резервную копию. `localis undo` откажется затирать файл,
если после применения его уже менял человек или другой инструмент.

## Privacy Gateway вместо обещания приватности

Самая важная часть Localis — не название провайдера, а видимая граница. Команда
`localis privacy` показывает точный список файлов, объём, количество замен и хеш
payload. По умолчанию содержимое payload даже не попадает в JSON-отчёт.

```bash
localis privacy . --file src --file package.json
localis ask "Объясни поток авторизации" . --dry-run
```

Секреты, токены, ключи, пароли и PII маскируются до запроса. Контекст ограничен
по числу файлов и байтам. Исходники помечаются как недоверенные данные, поэтому
инструкция внутри репозитория не должна становиться системной инструкцией для
модели.

Для локальной работы поддерживаются Ollama и LM Studio: их endpoints жёстко
ограничены `localhost`, `127.0.0.1` и `::1`. Отдельный OpenAI-compatible режим
позволяет осознанно подключить облачный HTTPS API, автоматически загрузить его
каталог моделей и передавать только ограниченный, предварительно очищенный
контекст. API-ключ не принимается как аргумент командной строки; desktop держит
его только в памяти текущей сессии.

## Модель предлагает, транзакция изменяет

Мы специально не дали модели инструмент записи. Она возвращает JSON по строгой
схеме: путь и полное новое содержимое. Затем детерминированное ядро заново
проверяет структуру, путь, размер, текущий хеш и строит unified diff.

Это разделение кажется формальностью, пока не происходит первая ошибка. Если
модель придумала путь `../../something`, исходник успел измениться или backup
повреждён, операция останавливается до записи. Безопасность здесь является
свойством потока, а не качеством промпта.

## Test Intelligence и Ship Check

Релиз — больше, чем отсутствие найденного секрета. Localis обнаруживает
проверки Node.js, Python, Rust и Go, запускает их без shell-интерполяции,
ограничивает захваченный вывод и редактирует чувствительные значения.

```bash
localis test . --dry-run
localis test .
localis ship .
```

`ship` объединяет аудит, тесты, typecheck, lint и production build. Результат —
понятное `READY TO SHIP` или список блокеров, а `--json` делает тот же контракт
пригодным для CI.

## Desktop без тяжёлого Electron

Для графического интерфейса мы выбрали Tauri 2 + React + TypeScript. Получился
локальный «контрольный стол»: выбор репозитория, evidence ledger, Privacy
Boundary и release rail. Rust bridge разрешает только четыре операции — audit,
privacy, ship и doctor — канонизирует путь и вызывает CLI массивом аргументов,
не shell-строкой.

Tauri сохраняет приложение лёгким и даёт явную модель capabilities. В Localis
WebView получает только базовые разрешения и нативный выбор папки. Телеметрия и
remote origin не настроены.

## Почему проект открыт

Privacy-first инструмент должен быть проверяемым. Localis опубликован под
Apache License 2.0: код можно изучать, модифицировать и использовать в
коммерческих проектах с сохранением условий лицензии. Архитектурные решения,
privacy contract и change-plan protocol описаны рядом с кодом.

Проект не обещает магическую безопасность. Pattern-based правила могут
ошибаться, а редактирование не заменяет secret manager, review и ротацию
скомпрометированных ключей. Наша цель практичнее: сделать безопасный путь
наиболее понятным и удобным.
