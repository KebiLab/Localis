# localis-core

The local-first scanner, privacy boundary, provider adapters, change-plan validation, and release checks used by [Localis](https://github.com/KebiLab/Localis).

```ts
import { runAudit, runShipCheck } from "localis-core";
```

Most users should install the `localis` CLI instead:

```bash
npm install --global localis
```
